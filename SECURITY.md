# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability in SheetStream, please do not disclose it publicly in an open GitHub issue.

Please report vulnerabilities privately to the project maintainers via GitHub private vulnerability reporting or by contacting the maintainers directly.

You should receive an acknowledgement within 48 hours. Valid vulnerabilities will be patched promptly and released in a subsequent patch version.
